# Omitted Assets

The example render images for this skill (approximately 81 MB of PNG files, such as `data_lakehouse.png` and `bio_signaling_pathway.png`) were omitted from this repository because their combined size exceeded the push gateway limit and repeatedly caused the upload to fail.

The skill itself (`SKILL.md`, README, plugins, and docs) does not require these example renders to function.

The original images are available from the upstream source repository `plutolei/paperbanana-skill` on GitHub.
