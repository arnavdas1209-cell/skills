# Skills

This repository contains 57 agent skills installed from the
`awesome-research-skills` and `awesome-academic-skills` lists.

The skills cover three broad areas:

- **Diagrams, graphs, and figures** — creating and editing scientific
  figures, plots, schematics, and diagrams.
- **Mechanical, metallurgy, and materials engineering** — simulation,
  meshing, solvers, ontologies, and related computational workflows.
- **Report and paper writing** — academic papers, slides, lab reports,
  and research dissemination.

Each skill lives in its own top-level folder containing a `SKILL.md`
plus any supporting files (`references/`, `templates/`, `scripts/`, etc.).

A few folders carry a `NO_LICENSE.txt` instead of a license file because
their upstream source shipped no license. See `SKILLS_INSTALL_REPORT.md`
for per-skill provenance and license details.
